# 桌边 · 单机与联机桌游

新增《武穴麻将》：固定四座，支持离线单机与联机，联机至少两名真人准备后可由电脑补齐；关闭补位时需四名真人准备。万、筒、条及字牌采用原创 HTML/CSS 牌面。可吃、碰、明暗杠、补杠、特殊杠、自摸与抢杠；多个玩家响应同一张牌时按规则优先级结算。两骰点数和从庄家起顺时针选牌墙，大骰子定翻皮垛，皮子数字定后续跳垛数（字牌跳一垛），开局可查看具体位置。庄家不加斤。

麻将按双方杠数之和逐家算斤，赖子杠计两杠，16斤封顶。门面清、七对赢牌时三家都付款，其他情况未开口者免付。初始金额为1斤和2斤各1元、4斤2元、8斤4元、16斤8元；银顶两家各10元，金顶三家各15元，可在开局前设置。每局结果自动缓存到参与人的浏览器，结束本场后可在首页／联机页查看和下载JSON；不累计跨场钱包。两局之间离席会结算旧场，换人重新开场。联机刷新可恢复同一身份；服务器停止后房间清空，本机此前已收到的结果仍保留。

具体规则、骰子算法及首版补充约定见 [武穴麻将规则核对稿](docs/mahjong-rules-review.md)。检查新增联机流程可运行 `node tests/mahjong-http.integration.js`。

## 本机开设联机房间

需要 Node.js 20 或更新版本。在项目目录运行 `npm start`，然后打开 `http://127.0.0.1:8080/`。入口可选择“游客单机”或“临时身份联机”；直接双击 `index.html` 仍可离线单机游玩。联机服务无需安装 npm 依赖。

联机玩家输入昵称后获得随机身份 ID。同一浏览器刷新可恢复；服务器停止后身份、房间和联机成绩全部清空。全站最多 10 个身份同时在线。可以从房间列表直接加入无密码房间、输入房间码和密码加入，或分享房间的邀请链接。房主设置游戏与座位上限，至少两名在线玩家准备好即可开局，无需等待所有人；只让已准备玩家参与，德州全部由真人游玩，其他游戏可以用电脑补齐。联机 Flip 7 也支持两人开局，单机仍为 3–6 人。未准备的房内成员和后来加入的候场玩家可随时准备：德州现金桌在两手之间有空位时自动入座，其余游戏及锦标赛在下一整局有空位时自动参与，候场准备状态保留到下一局。快捷短语固定在屏幕底部，各游戏的气泡显示在实际牌桌对应玩家的头像旁。

“创建房间”和“加入房间”可在页面顶部切换；邀请链接优先显示加入页，也可直接粘贴完整邀请链接。切换游戏、玩法或收到实时房间更新时会保留表单草稿，错误显示在对应输入框下方。德州联机不显示电脑难度，现金桌不显示升盲设置。各游戏的房间都有“玩法与操作”速查；联机查看说明时对局继续。邀请链接复制成功使用绿色提示，浏览器不允许自动复制时可在页面内手动复制。

局域网使用 `HOST=0.0.0.0 npm start`，其他设备打开本机局域网 IP 的 8080 端口。要让外网朋友临时加入，可在启动服务后另行安装 `cloudflared`，运行 `cloudflared tunnel --url http://127.0.0.1:8080`，分享它显示的 HTTPS 地址。房间内“复制邀请链接”会使用当前页面地址：分享给局域网朋友前请通过局域网 IP 打开房间，分享给外网朋友前请通过隧道 HTTPS 地址打开房间。临时隧道的地址每次可能变化，关闭隧道后外网入口失效；本机服务器仍必须保持运行。原 GitHub Pages 静态试玩页没有服务器，仍只提供单机。

联机现金桌使用固定初始筹码，不使用单机钱包或银行。新玩家在下一手带入一份初始筹码；两手之间可请求其他玩家同意后转让筹码，或直接赠送超出初始值的筹码。余额恰好等于初始值才能离席。房主手动开启每一手，设置的操作时限为 30–300 秒，默认 120 秒；在线超时可过牌时过牌，否则弃牌，离线超时弃牌。联机对局和单机存档、成就互不影响。

双击 index.html 即可在桌面浏览器中使用。运行时不需要网络、安装程序或本地服务器。将整个文件夹复制到另一台电脑仍可运行；请把导出的 JSON 存档也一并带走。

## 使用

1. 首次打开点击“开始选游戏”即可使用默认档案；德州初始资金及借款额度可在可选设置中调整。
2. 在首页选游戏、人数与难度；初次使用可从“先试 Flip 7”进入，电脑默认初级。德州可选择现金桌或锦标赛，设置初始筹码和盲注；开局错误显示在开始按钮旁，已填设置会保留。
3. 六款游戏各有一个独立进度槽。当前游戏未完成也可返回首页开启另一款；切换时原对局自动暂停，点击对应卡片“继续游戏”可恢复。每次只运行并计时一款游戏。
4. 顶栏可随时切换有图／无图、暂停、备份全部或加载存档。切换到其他标签页会自动暂停。
5. 游戏卡片或游玩页的“保存此游戏”打开保存窗口：首次选择 JSON 文件，后续点击“覆盖保存”更新同一个文件。“另存为…”可更换文件，“下载副本”保留带时间的备份。六款游戏与全部备份分别记住各自的文件。
6. “备份全部”保存整个档案，包含六个游戏、统计、成就和资金；从顶栏“加载存档”恢复全部备份或单游戏存档。“加载此游戏”仅替换这一款的进度、统计与历史。德州独立存档也包含钱包和借款账目，其他游戏的存档不会更改德州资金。

直接覆盖文件需使用支持文件选择 API 的浏览器，例如桌面 Chrome / Edge；其他浏览器提供“下载副本”。可在首次保存时选择本项目的 saves 目录。保存窗口打开期间，计时和电脑行动暂停；取消选择或保存失败后，可在窗口内重试、另存为或关闭继续游玩。错误显示在保存按钮附近。

浏览器会尽力记住选择的文件，刷新或重新打开后可以继续覆盖；必要时会再次请求该文件的写入权限。通过原生文件选择窗口加载并确认的 JSON，也会成为对应范围的覆盖目标。清理浏览器存储、更换浏览器或项目地址后，可能需要重新选择；通过普通文件上传加载时，首次覆盖也需要选择文件。

浏览器暂存会尽力在刷新后恢复六个对局，但本地文件地址下不同浏览器对本地存储的处理不同。需要可靠迁移或长期留存时，请主动导出 JSON。加载前会说明替换范围并请求确认；旧版单对局存档自动迁移，原统计及资金保留。导入后对局均暂停，已获得的成就在单游戏导入时合并保留。

首页可重置浏览器中的本地档案，重新设定一次性的初始资金；重置前请先导出需要保留的 JSON。

首页的有效游玩时长包含未结束对局中已经游玩的时间；暂停与查看单机规则期间不计时。完成或结束对局时才将对应时长计入已结束统计，避免重复累计。

## 游戏与资金

- 《胡闹运动会》（Magical Athlete）：2–6 人，36 位不同能力的选手。蛇形选角或随机组队，四场比赛每位角色只能使用一次；双人每队 8 位角色、每场各上两位，按赛前选择的固定顺序行动。可选择温和／狂野交替或全程温和赛道，冠军奖分依次为 3／4／4／5，亚军为 1／2／2／3，最高总分获胜、同分共享排名。技能选择在赛道下方，角色能力及最新结算显示在旁边；正常（每条提示约 1.2 秒）、快速或逐步播放可随时切换。逐步按钮固定在赛道上方，每次推进一条可见提示或电脑行动，轮到真人选择技能时暂停；最近比赛过程默认展开。棋子和角色卡采用本项目原创 AI 图集，无图模式以名字区分。
- 《Flip 7》：3–6 人，真人和电脑轮流翻牌或收分，94 张标准牌。重复数字爆牌归零，第二次机会可抵消一次；集齐七个不同数字立即结算并额外加 15 分。冻结、连翻三张、加分牌与倍率均可用；倍率只作用于数字合计。200 分以上最高分并列时全员加赛，轮末由玩家确认继续。页面显示所有人的公开牌、累计分、特殊牌目标，以及剩余牌对应的重复概率。
- 《璀璨宝石》：基础版 2–4 人、90 张发展卡和 10 位贵族。
- 《马戏星探》：2–5 人；双人按双人规则进行两轮，其余人数按人数轮数进行。每轮发牌随机牌序，每张牌独立随机数字朝向；双人第二轮使用预先留出的另外 22 张牌。开局可以整手翻面并反转顺序，确认后不能单张调整方向或重新排序。电脑也只能在原手牌和整手翻面之间选择。
- 德州扑克：2–10 人无限注现金桌。真人钱包跨牌桌保存，桌面筹码用完后可直接“用钱包买入，继续下一手”，保留当前牌桌和其他玩家的余额。补买通常补至初始买入；钱包不够补满时，可用现有余额买入（余额少于大盲时按短筹码全下规则参与）。电脑仅在筹码归零后，下一手自动补买初始金额；仍有筹码时保留余额。电脑补买使用独立虚拟资金，无钱包或借款上限，不扣真人钱包；所有补买均计入累计买入，不算盈利。真人可在两手之间补买、借款、还款或离桌。离桌需要二次确认，取消时继续保留当前牌桌。
- 德州锦标赛：在德州扑克设置页选择“锦标赛 · 争夺冠军”。2–10 人，每人使用相同初始比赛筹码，可设置小盲、大盲及初始筹码（至少为初始大盲的 20 倍）。免费参赛，比赛筹码独立于钱包，结束后不兑换钱包资金。你和电脑都不能补买，输光永久淘汰；最后留下的一人获得冠军。盲注默认每 10 手翻倍，可设置 1–100 手，填 0 则全程固定；升盲在下一手开始时生效，盲注最高不超过全场筹码。庄位、盲注和发牌跳过淘汰席位，两人时庄位支付小盲。名次按淘汰顺序结算，同手淘汰者按这一手开始时的筹码排名，相同筹码共享名次。页面显示剩余人数、当前筹码排名和升盲进度；当前筹码排名不等于最终名次。真人淘汰后可自动或逐手观战到冠军产生，也可以保存、暂停或换桌；名次确定后可直接结算离桌，记录完成场次、实际名次、游玩时间和对应成就，无需等待电脑决出冠军。名次确定前退出仍会放弃本场，不计完成与胜利。现金桌与锦标赛共用德州进度槽，存档保留玩法、淘汰名次和盲注级别。

锦标赛保留当前各难度的电脑下注策略。固定筹码和淘汰规则消除了无限补买的影响，但不会让高难度电脑减少翻牌前的激进加注；电脑按相同比赛规则争夺最后一个存活席位，没有新增针对夺冠概率的决策算法。

游玩界面采用桌面布局：璀璨宝石市场与自己的筹码、永久折扣并列，对手的各色资源公开显示；德州座位围绕公共牌，每个座位显示最近动作，操作按钮靠近自己的底牌；马戏星探在中央舞台下方展示有序手牌。

六款游戏均可从“规则 / 帮助”查看速查说明，查看期间暂停计时与电脑行动。璀璨宝石显示折扣后费用、资源缺口及购买预览；马戏星探先预览表演组合，招募时明确选择朝上的数字并预览插入位置，每轮结算后由玩家继续。窄屏宝石市场按等级切换并固定资源摘要，德州公共牌与座位改为纵向排列，无需横向滑动。

德州下注区显示最低／最高总额及本次需支付的筹码。每手摊牌后，在座位和“本手结果与最佳五张”中显示赢家、获奖金额、最佳牌型、点数、踢脚及本手盈亏，例如“同花 · A / K / J / 9 / 4”“葫芦 · Q 三条 + 9 对”。最佳五张牌直接展示，赢家使用的公共牌突出显示。弃牌玩家标为已弃牌，未摊牌直接获胜时不公开电脑底牌。牌力说明保存在对局记录中，已结束手牌的旧存档也能自动显示。

德州牌桌下方的“本轮手牌历史”按手保留公共牌、公开的底牌、最佳五张、筹码盈亏、结算及行动过程；展开任意一手即可回看，未摊牌的电脑底牌继续保密。逐手历史随当前牌桌存档保存，现金桌离桌结算或锦标赛结束／退出后随牌桌清空。旧存档中此前被短日志覆盖的行动无法恢复，新手牌从本版本起完整记录。

## 成就

共 37 个成就，首页按通用和五款游戏分组显示条件、解锁状态及累计场次进度。德州组内分为“现金桌与通用”和“锦标赛”，比赛筹码与现金盈利成就分别计算。

锦标赛新增 7 个成就：

| 成就 | 解锁条件 |
| --- | --- |
| 锦标赛初体验 | 完成一场锦标赛 |
| 最后的赢家 | 首次夺得锦标赛冠军 |
| 决赛席位 | 在 6 人及以上锦标赛获得前两名 |
| 满桌称王 | 在 9 人及以上锦标赛夺冠 |
| 高手擂台 | 在高级电脑难度的锦标赛夺冠 |
| 绝境加冕 | 曾在一手发牌前不足 5 个大盲，最终夺冠 |
| 筹码登峰 | 一手结算后筹码达到初始筹码的 3 倍 |

“绝境加冕”检查发牌、缴盲前的实际余额，不把全下投入造成的桌面余额归零算作低谷。“筹码登峰”按已结算最高筹码记录，游玩中达到即可提示；最高筹码与短筹码经历随锦标赛存档保留。名次确定后离桌即可结算完赛成就；夺冠成就在玩家赢得冠军时结算。名次未确定前退出不计完赛。加载旧存档时，会按已有锦标赛完成记录补发能确认的成就；旧记录未保存的人数、难度和短筹码经历不会被推测补发。

游玩中达成的成就会就地提示，结算时达成的成就显示在“本场新成就”。加载旧档会根据已有统计补发累计类成就；已有解锁保留。“压轴好戏”仅统计真人亲自打出的组合，不计电脑表演。德州翻倍及盈利条件只统计现金桌，按累计买入计算，借款和追加买入不算盈利。锦标赛夺冠计入德州胜利和通用胜利成就，不把比赛筹码算作现金盈利。

- [《璀璨宝石》出版商规则](https://www.spacecowboys-games.com/game/splendor/)
- [《璀璨宝石》90 张卡数据交叉核对资料](https://github.com/boardgamers/splendor/blob/main/packages/engine/src/data.ts)
- [《马戏星探》出版商介绍](https://oinkgames.com/en/games/analog/scout/)
- [《马戏星探》规则 PDF](https://www.hras.cz/user/related_files/new_edition_scout_rules_eng.pdf)
- [德州扑克规则](https://www.pokerstars.com/poker/learn/lesson/texas-holdem-rules/)
- [Magical Athlete 出版商](https://www.cmyk.games/products/magical-athlete)
- [Magical Athlete 官方规则 PDF](https://iello.fr/wp-content/uploads/2026/02/Magical-Athlete_Rulebook_FR_Light.pdf)
- [运动会官方 FAQ 2.0，2026 年 8 月更新](https://iello.fr/athletes-de-compete-tatillon-repond-a-vos-questions/)
- [赛道及奖分实物照片，用于核对组件](https://geekdad.com/2025/11/wacky-racing-in-magical-athlete/)
- [Flip 7 出版商](https://theop.games/products/flip-7)
- [Flip 7 出版商规则与 FAQ](https://rules.dized.com/game/dPDRM857TU-BFRF7LzGE0g/flip-7)
