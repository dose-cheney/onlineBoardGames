将 JSON 存档放在这里，复制整个文件夹时即可连同存档带走。

桌面 Chrome / Edge 等支持文件选择 API 的浏览器：点击“保存此游戏”或“备份全部”，首次选择本目录中的 JSON 文件，之后用“覆盖保存”更新同一个文件。“另存为…”可更换文件，“下载副本”另留带时间的备份。

其他浏览器：使用“下载副本”，再将下载的文件自行移入本目录。

五款游戏及全部备份各自记住选择的文件；通过原生文件选择窗口加载并确认的 JSON，也会成为对应范围的覆盖目标。刷新后通常无需重新选择；清理浏览器存储或移动整个项目后可能需要重新选择，并授权写入。

五个游戏可分别导出、加载独立 JSON；“备份全部”包含五个进度槽。德州独立存档包含钱包及借款账目，加载时会一并恢复；加载其他桌游存档会保留钱包及其他游戏进度。
